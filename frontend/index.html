📜 Asli Niyam (classic)

  1. 📝 Chits banti hain: Raja 1000, Rani 800, Mantri 700… Chor 0. Sabko ek secret chit.
  2. 👑 Raja khud ko reveal karta hai aur pukarta hai — “Mera Mantri Kaun?”
  3. 📜 Mantri (4 players me Sipahi/Police) saamne aata hai, chor ko guess karta hai.
  4. ✅ Sahi pakda → Mantri apne points rakhta, Chor 0. ❌ Galat → Mantri 0, Chor Mantri ke points le jata!
  5. 👑 Rani, Senapati, Sipahi… sab fixed points. 5–10 rounds ke baad sabse zyada total = Raja of Rajas! 🏆

          🔌 Game Server (Render)

          Frontend Netlify par hai, realtime server Render par. Apna Render URL yahan paste karo — sab players same URL use karein.

          Render free plan pehla connect 30–60 sec le sakta hai (cold start). render.com

          ❓ Kaise khele? (school style)

          1. Host Create kare (players 4–10, rounds 5). Code share kare.
          2. Sab Join karein. Min 4 hone par Host Start.
          3. Har round me secret chit: Raja 1000, Rani 800, Mantri 700, Senapati 600, Sipahi 500, Kotwal 400, Praja 300, Villager 200, Sahayak 100, Chor 0 (jitne players, utni top chits + Chor).
          4. 4 players me guesser = Sipahi (Police) 500. 5+ me guesser = Mantri 700.
          5. 👑 Raja button dabata hai “Mera Mantri Kaun?” → Mantri reveal → suspect chunno.
          6. Sahi = Mantri safe, Chor 0. Galat = Mantri 0, Chor ko Mantri wale points!
          7. Fixed roles hamesha apne points rakhte. End me highest total jeetta 🏆
